Eigene Cloud

Deine Seiten, Boards und Datenbanken auf allen Geräten und zum Teilen, auch wenn dein Computer aus ist. Die Cloud läuft auf einem kleinen Server, den du selbst mietest. Deine Daten liegen bei dir, nicht bei efeu oder anderen.

Die Cloud ist freiwillig. Ohne sie bleibt efeu wie bisher komplett auf deinem Computer.

In vier Schritten

1

Server mieten

Zum Beispiel bei Hetzner (Konto anlegen, dann „Server erstellen“):

  1. Typ: der kleinste, etwa CX23 oder CAX11 (2 Kerne, 4 GB). Kostet rund 7 € im Monat, stundenweise abgerechnet.
  2. Standort: Nürnberg oder Falkenstein.
  3. Image: Ubuntu (aktuelle Version).
  4. Netzwerk: öffentliche IPv4 anlassen.
  5. SSH-Key: keinen. Dann kommt das root-Passwort per E-Mail.

Andere Anbieter gehen genauso: Nötig sind Ubuntu oder Debian, root-Zugang mit Passwort und eine öffentliche IPv4-Adresse.

2

In efeu einrichten

  1. In efeu ⌘, (Windows: Strg+,) → Eigene Cloud → Eigenen Server einrichten.
  2. IP-Adresse und Passwort aus der E-Mail eintragen, „Einrichten“ klicken.
  3. efeu installiert alles selbst: den efeu-Server, HTTPS, automatische Sicherheitsupdates und tägliche Sicherungen. Das dauert etwa 3 bis 5 Minuten.

Verlangt der Anbieter beim ersten Anmelden ein neues Passwort, setzt efeu ein sicheres und zeigt es dir einmal an. Das Passwort wird sonst nirgends gespeichert.

3

Handy verbinden

  1. Eigene Cloud → Weiteres Gerät verbinden → Handy oder Tablet.
  2. QR-Code mit der Kamera scannen, warten, bis deine Seiten erscheinen.
  3. In Safari Teilen → „Zum Home-Bildschirm“. efeu liegt dann wie eine App auf dem Handy.
4

Weitere Computer und Teilen

  1. Anderer Computer: efeu installieren, Eigene Cloud → Mit bestehender Cloud verbinden, Adresse und Code eintragen.
  2. Teilen: auf einer Seite oben rechts „Teilen“, Person einladen, Link schicken. Gäste arbeiten im Browser live mit, auch wenn dein Computer aus ist.

Fragen zur Cloud

Brauche ich eine eigene Domain?

Nein. Ohne Domain bekommt die IP-Adresse deines Servers ein echtes HTTPS-Zertifikat von Let's Encrypt, das sich selbst erneuert. Wer eine Domain hat, trägt sie bei der Einrichtung unter „Erweitert“ ein; sie muss vorher auf die IP-Adresse zeigen.

Kann ich offline weiterarbeiten?

Ja. Auf dem Computer arbeitest du wie gewohnt weiter, Änderungen werden übertragen, sobald die Verbindung wieder da ist. Haben zwei Geräte gleichzeitig an derselben Seite geschrieben, führt efeu beides zeichengenau zusammen; bei Boards und Datenbanken zählt je Element bzw. Zelle die neuere Änderung.

Wie bleibt der Server aktuell und sicher?

Ubuntu installiert Sicherheitsupdates automatisch. Den efeu-Server bringt die App beim nächsten Verbinden auf ihren Stand; der Server nimmt nur Updates an, die mit dem Schlüssel der efeu-Releases signiert sind. Jedes Gerät hat einen eigenen Schlüssel und lässt sich in den Einstellungen sofort entfernen.

Und wenn etwas kaputtgeht?

Der Server sichert die Datenbank jeden Tag und behält 14 Tage (Ordner /var/lib/efeu/backups). Außerdem hat jeder verbundene Computer eine vollständige Kopie aller Seiten und macht weiterhin seine eigenen täglichen Backups.

Wer kann meine Daten sehen?

Nur du, deine Geräte und die Personen, denen du Seiten freigibst. Der Server gehört dir; efeu hat keinen eigenen Server und sieht nichts. Wie bei jedem gemieteten Server hat technisch auch der Anbieter Zugriff auf die Hardware.

Geht das auch mit Docker oder auf einem NAS?

Ja. Jedes Release enthält efeu-server.mjs und efeu-web.tar.gz; im Quellcode liegt ein Dockerfile (server/Dockerfile). Der Server braucht Node.js 24, Daten liegen in EFEU_DATA, HTTPS übernimmt ein Proxy davor. Mit node efeu-server.mjs pairing-code bekommst du einen Code, mit dem sich efeu unter „Mit bestehender Cloud verbinden“ anmeldet.
